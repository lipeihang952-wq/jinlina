# 金丽娜 · 纪录片导演 · 记者 · 作家

一个关于金丽娜（CCTV-7《军事纪实》纪录片编导、主编）的单页网站。

**在线地址：<https://lipeihang952-wq.github.io/jinlina/>**
纯静态（HTML + CSS + JS），所有字体、脚本、图片都放在本仓库里，不依赖谷歌字体或境外 CDN，方便国内访问。

## 网站里有什么

| 区块 | 内容 | 互动 |
| --- | --- | --- |
| 首屏 | 肖像、名字、一句话介绍 | **暗房显影**：照片默认黑白，鼠标移过的地方恢复彩色，点击全部显影；照片会跟着鼠标 3D 倾斜 |
| 人物 | 生平与数字 | 大字随滚动逐字点亮、数字滚动 |
| 身份 | 记者 / 编导 / 作家 / 主持人 | 手风琴卡片：鼠标移上去（手机上点一下）展开 |
| 作品 | 13 部作品 | 电脑上向下滚动，胶片会横向移动；手机上左右滑动；点开看详情，可以上一部 / 下一部 |
| 现场 | 2012 年冬《走边关》内蒙古段 | 雪夜地图：滚动时路线自西向东逐站点亮；移动鼠标会改变风雪方向 |
| 打一板 | 14 个真实故事 | 点击场记板“打板”（有合成的打板声，可关），每打一板解锁一个故事，看能不能集齐 |

| 荣誉 | 称号与作品获奖 | 滚动字幕、悬停高亮，点击查看对应作品 |

另外：自定义光标（电脑上）、平滑滚动、顶部阅读进度条、首次打开的“冲洗胶片”片头。系统开启“减少动态效果”时会自动关闭大部分动画。

## 本地预览

```bash
cd ~/jinlina-website && python3 -m http.server 5317
```

然后打开 <http://127.0.0.1:5317>。

### 关于字体

为了国内也能快速加载，中文衬线字体（思源宋体）、书法字体（马善政）和英文字体都**只保留了网站用到的字**（总共约 350 KB）。
如果新增的文字里有原来没出现过的字，那几个字会用系统自带的宋体显示，不影响阅读。想让新字也用网站字体，可以重新生成：

```bash
pip3 install fonttools brotli
# 先把原始字体放进 fonts_src/（NotoSerifSC[wght].ttf、MaShanZheng-Regular.ttf、InstrumentSerif-Regular.ttf、InstrumentSerif-Italic.ttf，均可在 github.com/google/fonts 下载）
python3 tools/subset_fonts.py . fonts_src
```

## 上线与更新

网站托管在 GitHub Pages，改完文件后提交并推送，几分钟后线上就会自动更新：

```bash
cd ~/jinlina-website && git add -A && git commit -m "更新内容" && git push
```

### 国内访问

GitHub Pages（`*.github.io`）在中国大陆一般可以打开，但速度和稳定性不保证，偶尔会被干扰；微信里打开外部链接也可能出现提示。
如果希望国内长期稳定、在微信里顺畅打开，推荐：注册一个域名 → 完成 ICP 备案 → 把本文件夹上传到腾讯云 COS / 阿里云 OSS 的静态网站托管（或任意国内服务器）。网站是纯静态的，整个文件夹直接上传即可，不需要改代码。
